# Security / Segurança

**English** · [Português](#português)

If you find a security problem in Thirium Link, please **report it privately** using
[Report a vulnerability](https://github.com/Nanokaso/thirium-link/security/advisories/new) (Security tab).

Please don't open a public issue or share the details elsewhere until it's fixed. Thank you!

---

## Português

Se você encontrar um problema de segurança no Thirium Link, por favor **relate de forma privada** em
[Report a vulnerability](https://github.com/Nanokaso/thirium-link/security/advisories/new) (aba Security).

Por favor, não abra uma issue pública nem compartilhe os detalhes em outro lugar até a correção sair. Agradeço a ajuda!
